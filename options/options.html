Phòng Thử Nghiệm Phím Tắt

Kiểm tra khả năng mở rộng của phím tắt trên cả ô nhập liệu tiêu chuẩn lẫn trình soạn thảo phong phú (WYSIWYG Rich Text).

1. Ô Nhập Tiêu Chuẩn (Input & Textarea)

Plain / Markdown

Kiểm tra khi gõ trên khung chat, thanh tìm kiếm hoặc form nhập liệu đơn giản.

2. Trình Soạn Thảo Phong Phú (WYSIWYG)

WYSIWYG Rich Text

Mô phỏng khung soạn thảo của Gmail, Notion, Slack, Docs. Markdown sẽ tự bung thành chữ in đậm, link, danh sách.

Kịch Bản Tự Động Hóa (Macro Automation)

Tự động điền biểu mẫu, chọn dropdown và bấm nút Submit theo đúng chuỗi thao tác đã ghi.

💡
Cách tạo kịch bản tự động hóa:

1. Mở trang web bạn muốn tự động điền form (ví dụ: trang Ticket CRM, Admin...).
2. Bấm icon Auto Text Expander trên thanh tiện ích Chrome → Chọn "Ghi Thao Tác".
3. Thao tác trên form như bình thường (nhập dữ liệu, chọn mục, bấm submit) → Bấm "Dừng & Lưu".

Sao Lưu & Khôi Phục Dữ Liệu

Xuất danh sách phím tắt để lưu trữ, hoặc chia sẻ sang máy tính khác dưới dạng JSON hoặc CSV.

Xuất Dữ Liệu (Export)

Tải toàn bộ danh sách phím tắt và cấu hình về máy tính cá nhân để lưu trữ an toàn.

Định dạng JSON (.json)

Đầy đủ thông tin, hỗ trợ đầy đủ Markdown đa dòng và cấu hình cài đặt.

Định dạng Excel / CSV (.csv)

Dễ dàng mở và chỉnh sửa hàng loạt bằng Microsoft Excel hoặc Google Sheets.

Nhập Dữ Liệu (Import)

Tải file .json hoặc .csv đã lưu trước đó vào extension.
